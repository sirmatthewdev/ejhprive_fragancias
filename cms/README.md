# EJH PRIVÉ: panel de administración

Payload CMS 3 sobre Next.js. Gestiona pedidos (con seguimiento), stock y usuarios de la tienda.
Las instrucciones están en el README de la raíz del proyecto.

```sh
npm install
cp .env.example .env   # completar PAYLOAD_SECRET
npm run seed           # primera vez
npm run dev            # http://localhost:3000/admin
```
